Q: Tell me about the AI chatbot project.
A: Layth designed, built and deployed an AI resume assistant for an executive client (a CIO/CTO). It's a retrieval-augmented (RAG) chatbot: the client's resume and Q&A are indexed with BM25 search, the most relevant passages are retrieved for each question, and an LLM (Abacus.AI RouteLLM, with Anthropic Claude support) streams a grounded answer. It installs on any website, including the client's WordPress site, with one line of JavaScript, has an animated waving robot mascot and brand-matched colors, offers the client's booking link, and lets the client log in from inside the chat to upload Word files. It's deployed on Render with access locking and daily usage caps to control costs. The assistant on Layth's own site is built the same way.

Q: What technologies did Layth use for the AI chatbot?
A: Node.js and Express for the server, BM25 retrieval for RAG, Abacus.AI RouteLLM and the Anthropic Claude API for the language model, a Shadow DOM JavaScript widget, mammoth for reading Word files, Python and Pillow for the mascot artwork, Playwright and node:test for testing, and Render with an infrastructure-as-code Blueprint for deployment.
